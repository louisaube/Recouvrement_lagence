Renforcer la recette du socle sur cinq points que le test de mutation a montrés non vérifiés, puis corriger le code là où ces nouveaux tests échouent. Aucune fonctionnalité nouvelle, aucun changement de contrat.

1. Empreinte de mot de passe illisible. Si l'empreinte enregistrée pour un compte n'est pas une empreinte bcrypt valide (donnée corrompue, valeur vide, texte quelconque), la connexion doit être refusée exactement comme un mauvais mot de passe : 401 security.invalid_credentials, même corps, aucun jeton ni cookie.
2. Corps de requête refusés (98-arbitrages.md, Q-PLAT-04). Un corps JSON de plus de 1 Mio reçoit 413 avec le code api.payload_too_large ; un JSON mal formé reçoit 400 api.validation.incoming_failed. Dans les deux cas : corps d'erreur limité à status, code, message (et details pour la validation), sans pile ni chemin de fichier, et rien n'est écrit en base.
3. Aucun secret dans les journaux (EXI-PLAT-05). Quand une requête à la base échoue de façon inattendue, la réponse est 500 api.unknown_error, et le journal technique du serveur (api/.server-test.log) ne contient ni la requête SQL, ni ses paramètres, ni empreinte de mot de passe, ni l'e-mail concerné ; il contient l'identifiant de requête (X-Request-Id). Le moyen de provoquer l'erreur dans le test est libre (par exemple une contrainte posée temporairement en base par le test).
4. Lecture stricte du jeton. Un en-tête Authorization qui n'est pas exactement « Bearer <jeton> » (mot de passe en trop, deux jetons, préfixe inconnu) donne 401 security.invalid_token, même si le jeton qu'il contient est valide. Le cookie de session renvoyé par un client (même nom que celui posé à la connexion, éventuellement parmi d'autres cookies, avec ou sans espaces) authentifie l'appelant sur GET /auth/current-user ; un cookie d'un autre nom ou sans valeur ne l'authentifie pas.
5. Algorithme du jeton. Un jeton signé avec un autre algorithme que celui du serveur (HS512 avec le même secret, ou alg « none ») est refusé : 401 security.invalid_token.

Les tests sont écrits avant toute correction, dans la recette boîte noire. Les droits ne changent pas.
